# Municípios brasileiros

`municipios_ibge.json` contém os 5.571 municípios retornados pelo serviço oficial de localidades do IBGE, com código IBGE, nome e UF. A aplicação importa essa lista para `cidades` ao inicializar o esquema, sem depender de conexão externa em execução.

Fonte: [API de Localidades do IBGE](https://servicodados.ibge.gov.br/api/v1/localidades/municipios?orderBy=nome), consulta realizada em 21/10/2026. A tabela de códigos municipais é mantida e atualizada pelo [IBGE](https://www.ibge.gov.br/explica/codigos-dos-municipios.php).
